# Quick Printable Tally Keyboard Card

Place this cheat-sheet next to your billing counter:

- **Accept / Add**: `Alt + A`
- **Create Ledger / Item**: `Alt + C`
- **Instant Save**: `Ctrl + A`
- **Cancel / Back**: `Esc`
- **Confirm**: `Enter`
- **Sales Voucher**: `F8`
- **Purchase Voucher**: `F9`
- **Receipt Voucher**: `F6`
- **Payment Voucher**: `F5`
