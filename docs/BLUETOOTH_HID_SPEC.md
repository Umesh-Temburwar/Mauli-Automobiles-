# Bluetooth HID Keyboard Implementation Specification

## USB HID Keyboard Usage Tables (Scan Codes)
- Arrow Up: `0x52`
- Arrow Down: `0x51`
- Arrow Left: `0x50`
- Arrow Right: `0x4F`
- Page Up: `0x4B`
- Page Down: `0x4E`
- Escape: `0x29`
- Enter: `0x28`
- Tab: `0x2B`
- Space: `0x2C`
- Backspace: `0x2A`

## Modifier Bitmasks
- Left Ctrl: `0x01`
- Left Shift: `0x02`
- Left Alt: `0x04`
- Left GUI: `0x08`
