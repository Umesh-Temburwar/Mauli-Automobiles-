# Numpad Mapping Specification

## Numeric Layout
```
[ 7 ] [ 8 ] [ 9 ] [ / ]
[ 4 ] [ 5 ] [ 6 ] [ * ]
[ 1 ] [ 2 ] [ 3 ] [ - ]
[ 0 ] [ . ] [Enter] [ + ]
```

## Keycode Table
- Key 0-9: `0x30` - `0x39` (or VK_NUMPAD0 - VK_NUMPAD9 `0x60` - `0x69`)
- Key Decimal (.): `0x2E` (`0x6E`)
- Key Divide (/): `0x2F` (`0x6F`)
- Key Multiply (*): `0x2A` (`0x6A`)
- Key Minus (-): `0x2D` (`0x6D`)
- Key Plus (+): `0x2B` (`0x6B`)
